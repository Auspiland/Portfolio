My Role

PROJECT 02
#파이프라인구축#라벨정제#검색설계#VLM확장

A-project

기술 매뉴얼(PDF·이미지) 원문에서 의미 정보를 추출해 지식 그래프 + RAG로 구축하고, VLM으로 이미지까지 확장한 파이프라인.

My Role
  • 원문 데이터에서 의미 있는 정보를 추출해 그래프 구축 및 적재
  • 노드를 순회하며 관계 기반 노드 임베딩 벡터 강화 및 라벨 분류
  • LLM 태스크와 일반 파이썬 코드 처리를 LangGraph로 묶어 파이프라인 관리
  • 그림 포함 데이터까지 확장 — VLM 파이프라인으로 텍스트·이미지를 묶어 노드화
Architecture
  • 기술 매뉴얼 PDF → OCR → 정규화 텍스트·링크 추출
  • RAG 경로 — 청킹 → 임베딩(고밀도·희소) → OpenSearch 인덱스 → BM25 + 벡터 하이브리드 검색 → 근거 청크 포함
  • Knowledge Graph 경로 — 키워드·관계(S-P-O) 추출 → Neo4j 적재 → 라벨 분류 → 요약 그래프 임베딩 GNN → 검색 시 서브그래프 추출
  • 두 경로 결과를 통합 재랭킹·결합 → 최종 사용자 응답

PROJECT 03
#하이브리드검색#품질판단루프

미디어 AI Hybrid RAG

Graph RAG와 Normal RAG를 결합한 하이브리드 검색 시스템 — 질의 유형에 따라 경로를 분기하고, 품질 판단 루프로 답변을 보강.

핵심 설계
  • 질의문 분석 — 의도 분류 · 인덱스 선택 · 서브쿼리 분할, 멀티턴(지난 대화 Q&R) 컨텍스트 반영
  • 분기 — 표 데이터 활용 여부에 따라 경로 분리
  • Graph RAG — Neo4j(Hop 강화)·RDB 기반, Global search(Top-K Community) → 품질 판단 → Local · Drift search → 서브그래프 컨텍스트 생성 → Generation
  • Normal RAG — Top-K 문서·표 조회 → Reranking & Thresholding · Filtering → 컨텍스트 생성·Generation → 품질 판단(충분/불충분) 루프 → 자료 재요청 or 질의문 재작성
  • LLM-as-Judge로 최종 응답 품질 관리 → Chat
