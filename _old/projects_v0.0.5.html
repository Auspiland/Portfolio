PROJECT 02
#하이브리드검색#품질판단루프

미디어 AI Hybrid RAG

Graph RAG와 Normal RAG를 결합한 하이브리드 검색 시스템 — 질의 유형에 따라 경로를 분기하고, 품질 판단 루프로 답변을 보강.

핵심 설계
  • 질의문 분석 — 의도 분류 · 인덱스 선택 · 서브쿼리 분할, 멀티턴(지난 대화 Q&R) 컨텍스트 반영
  • 분기 — 표 데이터 활용 여부에 따라 경로 분리
  • Graph RAG — Neo4j(Hop 강화)·RDB 기반, Global search(Top-K Community) → 품질 판단 → Local · Drift search → 서브그래프 컨텍스트 생성 → Generation
  • Normal RAG — Top-K 문서·표 조회 → Reranking & Thresholding · Filtering → 컨텍스트 생성·Generation → 품질 판단(충분/불충분) 루프 → 자료 재요청 or 질의문 재작성
  • LLM-as-Judge로 최종 응답 품질 관리 → Chat
